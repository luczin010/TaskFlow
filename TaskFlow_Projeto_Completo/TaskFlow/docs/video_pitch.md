# Roteiro de vídeo pitch — até 4 minutos

**0:00–0:25 | Introdução**  
Olá, vou apresentar o TaskFlow, um sistema web de gerenciamento de tarefas criado para o cenário de uma startup de logística. A proposta é organizar atividades e tornar o andamento do trabalho mais visível.

**0:25–0:55 | Objetivo e método**  
Utilizamos Kanban, com as colunas A Fazer, Em Progresso e Concluído. Essa visualização ajuda a equipe a entender o que está pendente, o que está sendo executado e o que já foi finalizado.

**0:55–1:50 | Demonstração**  
Aqui posso cadastrar uma tarefa com título, descrição e prioridade. As tarefas aparecem no quadro. Posso mover uma tarefa entre os status e excluir quando necessário. A prioridade ajuda a destacar demandas urgentes.

**1:50–2:30 | GitHub e organização**  
O repositório está dividido em código-fonte, testes e documentação. O GitHub Projects organiza o backlog em cards, e o histórico de commits registra as mudanças de forma clara.

**2:30–3:10 | Qualidade**  
Criamos testes automatizados com Pytest para verificar carregamento da página, criação, mudança de status e exclusão de tarefas. O GitHub Actions executa esses testes quando há push ou pull request, ajudando a detectar erros cedo.

**3:10–3:35 | Mudança de escopo**  
Durante o projeto, simulamos uma mudança: acrescentamos prioridade baixa, média e alta às tarefas. A alteração foi motivada pela necessidade de destacar entregas críticas da operação logística e foi registrada na documentação e no Kanban.

**3:35–4:00 | Conclusão**  
O projeto mostra como organização, modelagem, versionamento, testes e integração contínua contribuem para um software mais confiável. Obrigado!
